Fetch a URL or search the web using an AI subagent that can extract, summarize, and answer questions. Slower and costlier than fetch; use fetch for raw content or API responses.

If a call runs long it moves to the background and returns a notice with a label; keep working and its result arrives later as a report under that label, which you can check with agent_status, steer with agent_send, or stop with agent_stop.
