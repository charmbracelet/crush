Save or delete a persistent project memory. Memories are markdown notes
that survive across sessions and are indexed in your system prompt.

Use save when you learn something durable and non-obvious: a user
correction or preference, a constraint not recorded in the repo, a
debugging insight that took real effort. Do not save what CRUSH.md,
AGENTS.md, or the code already records, or session-only details.
Use a short kebab-case name; overwrite an existing name to update it.
Read a memory with the view tool using the path from the memory index.
